# FangTang Skills

Personal AI skills for Codex, OpenClaw, Claude Desktop, and related agent workflows.

## Skills

- `skills/tdx-rps-query`: Query Tongdaxin stock and default industry-board RPS values from configured extended-data slots.
- `skills/fangtang-a-share-leader-radar`: Analyze A-share market leadership, strong sectors, and stock candidates with the platform-neutral Fangtang framework.

Each skill directory is intended to stay self-contained with its own `SKILL.md`,
scripts, references, and optional agent metadata.
